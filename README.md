# swift-ros2-common-interfaces

ROS 2 [common_interfaces](https://github.com/ros2/common_interfaces) and `tf2_msgs` for Swift,
generated by `swift-ros2-gen` from the upstream IDL of Humble, Jazzy, Kilted and Lyrical. One
Swift module per ROS package; depends only on
[swift-ros2-rosidl](https://github.com/swift-ros2/swift-ros2-rosidl), so it downloads no
native frameworks. Publish and subscribe with [swift-ros2](https://github.com/swift-ros2/swift-ros2).

```swift
.package(url: "https://github.com/swift-ros2/swift-ros2-common-interfaces.git", from: "1.0.0"),
// …
.product(name: "SensorMsgs", package: "swift-ros2-common-interfaces"),
```

| Module | ROS package |
| --- | --- |
| `StdMsgs`, `StdSrvs` | `std_msgs`, `std_srvs` |
| `GeometryMsgs` | `geometry_msgs` |
| `SensorMsgs` | `sensor_msgs` |
| `NavMsgs` | `nav_msgs` |
| `DiagnosticMsgs` | `diagnostic_msgs` |
| `ShapeMsgs`, `StereoMsgs`, `TrajectoryMsgs`, `VisualizationMsgs` | same names |
| `Tf2Msgs` | `tf2_msgs` (from `ros2/geometry2`) |
| `CommonInterfaces` | all of the above plus `BuiltinInterfaces` |

`tf2_msgs` is not in upstream's common_interfaces repository; it is here because this package
covers the standard message set of a REP 2001 `ros_base` install.

Names equal to a Swift standard-library type end in `Msg` (`StringMsg`, `BoolMsg`, `RangeMsg`).
Next to SwiftUI, qualify `Image` and `Path` with their module (`SensorMsgs.Image`).

## Upstream IDL and regeneration

The package has no submodules and ships no IDL: the generated Swift under
`Sources/<Module>/Generated/` is committed, so resolving this package downloads only Swift
sources. `idl.lock` pins one upstream commit per repository and distribution
(`<name> <url> <distribution> <commit>`), and `Scripts/fetch-idl.sh` (from swift-ros2-rosidl)
downloads exactly those commits into the gitignored `.idl/` cache, verifying each SHA.

| `idl.lock` repository | Packages | Role |
| --- | --- | --- |
| `common_interfaces` | the ten packages above | emitted (`--input`) |
| `geometry2` | `tf2_msgs` | emitted (`--input`) |
| `rcl_interfaces` | `builtin_interfaces` | dependency-only (`--dependency`); its types live in swift-ros2-rosidl |
| `unique_identifier_msgs` | `unique_identifier_msgs` | dependency-only (`--dependency`), for the `tf2_msgs` action wrappers |

`Scripts/generator-args.sh` prints the generator arguments; `Scripts/regenerate.sh` fetches the
IDL, runs the `swift-ros2-gen` of the rosidl version in `Package.resolved` and rewrites the
generated sources. To move to newer upstream IDL, change the commit on the line
(`git ls-remote <url> refs/heads/<distribution>`), run `Scripts/regenerate.sh` and commit
`idl.lock` together with the regenerated sources. CI fails when the committed sources differ
from what `idl.lock` produces.
